使用场景

快柠檬适合把「需要一条可切换的加密通道」当作工具，而不是把加速器整天开着不管。下面几类场景最常见，可对照自己的设备清单。

资料与办公。查阅海外文档、协作平台或开发者站点时，用桌面客户端固定规则分流，减少全局代理对内网打印和会议软件的干扰。

影音与资讯。在浏览器或系统播放器里访问区域受限内容时，先保证客户端规则能覆盖目标域名，再谈画质与缓冲。

出行与宿舍网络。公共 Wi-Fi 或不稳定校园网环境下，用手机客户端快速切换，避免每次重装。

多设备并行。同一订阅在电脑与手机间轮换时，关键是套餐允许的同时在线规模，以及每个系统都有可维护的客户端。

轻度游戏与实时通讯。若你主要补延迟而不是追求极限帧数，选择支持规则分流的客户端，把游戏与语音单独走加速通道即可。

小团队共用。需要统一说明导入步骤时，把本页操作说明转给同事，比口头传截图更不容易漏步骤。

客户端怎么选

强调客户端，是因为机场订阅本身只是一份配置入口。真正决定体验的是：它能否稳定导入通用订阅、能否按应用分流、能否在你的系统版本上长期维护。选择时用三条标准即可。

按系统对号入座

Windows 与 macOS 适合长时间挂着规则模式，改分流成本低。iOS 与 Android 适合通勤与临时热点。路由器适合覆盖电视和全家设备，但配置门槛更高，第一次建议先在电脑上验证订阅可用，再考虑下放到路由。

同一套订阅可以在多端导入，不代表要同时全开。同时在线数量以套餐说明为准；闲置设备记得断开，避免占满名额。

导入前先想清楚模式

全局模式省事，却容易把国内站点也绕一圈。规则模式（或分流模式）更适合日常：只有需要加速的域名走梯子，其余直连。若你分不清，先用规则模式打开一个需要加速的站点做验证，再逐步加规则。

操作说明

把第一次连接拆成四步。任何一步卡住，都不要跳步去「换节点碰运气」——多数问题出在客户端未更新订阅，或系统代理根本没打开。

  1. 确认场景与设备数

    写下你真正会同时开机的设备。只为偶尔用手机，不必按团队规模去选；若电脑和手机经常一起在线，以同时在线能力为第一筛选条件。

  2. 对照套餐完成订阅

    到本页套餐区查看各档说明。下单与续费以你实际购买流程为准。完成后，在账户页面复制订阅链接，不要把链接发到公开聊天。

  3. 安装客户端并导入 URL

    回到客户端区，按系统打开对应工具。在客户端里选择「从 URL / 订阅导入」，粘贴链接并更新。若提示证书或 VPN 配置权限，按系统对话框允许，这是建立隧道所必需的。

  4. 选线路、验证、再设分流

    先连一条延迟可接受的线路，用浏览器打开需要加速的站点。成功后再把常用应用加入规则。失败时依次检查：本地网络、客户端是否连通、系统代理开关、订阅是否复制完整。

常见问题

快柠檬是机场还是单独的 VPN 软件？

快柠檬按机场订阅来组织：你购买的是可导入到常用客户端的订阅能力，从而获得 VPN 梯子与网络加速。它不是只能装某一个封闭 App 的单一软件品牌页，所以客户端选择才被单独写成一章。

第一次使用应该从哪里开始？

先确定主力设备，打开本页客户端区完成安装，再去套餐区订阅并复制链接，最后在客户端里导入。不要先满世界找「破解客户端」——那会让订阅链接失效，也无从判断是线路问题还是软件被改过。

如何判断自己选对了客户端？

能顺利导入订阅、能更新节点列表、能在系统里打开代理或 VPN 配置，并且规则模式可工作，就算选对了。界面是否华丽并不重要。若某系统下有多个可用工具，选你能看懂分流设置的那一个，降低后期维护成本。

订阅链接能分享给朋友吗？

不建议。链接一旦公开，流量与在线名额会被占用，也难以追责。需要多人使用时，应选择匹配设备规模的套餐，并让每个人在自己的客户端里导入，而不是转发同一条链接到群组。

连上以后国内网站变慢怎么办？

多半是开了全局模式。改回规则 / 分流，让国内域名直连。若客户端支持绕过大陆或同类选项，优先打开。改完后刷新页面验证；仍异常时，关闭代理看本地网络本身是否拥堵，避免误判成「加速器坏了」。

套餐之间该怎么选，要不要看参数表以外的宣传？

以套餐模块里的流量、同时在线设备和支持方式为准。个人轻度浏览看入门档是否够用；多设备或对工单响应更敏感时再往上选。本页不额外编造节点数量、测速成绩或用户评价，避免和可核对信息冲突。

快柠檬官网下载和第三方市场有什么区别？

客户端请优先走本页客户端模块给出的入口，来源更清晰，也便于对照系统版本。应用商店或网盘转存包可能被二次打包。安装后若权限请求异常、无法导入标准订阅，应立刻停用并改回本页提供的渠道。
